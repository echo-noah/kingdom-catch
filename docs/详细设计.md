## 2. 配置设计（config.yaml）

```yaml
capture:
  monitor: 0            # 显示器索引，-1 为自动
  target_width: 1280    # 降采样到该宽度再识别
  fps: 10               # 抓帧率

vision:
  enable_diff_trigger: false   # 帧差触发开关（默认关，先验证主方案）
  diff_threshold: 30           # 帧差平均强度阈值 0-255
  diff_burst_ratio: 1.5        # 相对滑动均值突增倍数
  roi: null                    # [x, y, w, h]，null = 全屏
  templates:
    ball_throw:     { path: templates/ball_throw.png,     threshold: 0.80 }
    catch_success:  { path: templates/catch_success.png,  threshold: 0.82 }
    catch_fail:     { path: templates/catch_fail.png,     threshold: 0.82 }
  color_detect:
    enable: false
    success_color: [25, 180, 180, 35, 255, 255]  # HSV 上下界（游戏实测后填）
    success_min_ratio: 0.03    # 像素占比下限
  ocr:
    enable: true
    keywords: { "成功": success, "失败": fail }

state_machine:
  throw_timeout_s: 5.0    # 丢球后多久内未出结果 → UNKNOWN
  result_timeout_s: 6.0   # 结果界面停留判定窗口
  cooldown_s: 3.0         # 结果后冷却，防同事件重计

stats:
  csv_path: output/stats.csv
  save_debug: true        # 事件发生时保存标注帧
```

## 3. 模块设计

### 3.1 capture/screen.py

```python
class ScreenCapture:
    def __init__(cfg): ...          # mss 实例，SetProcessDpiAwareness(1)
    def grab(self) -> np.ndarray:   # BGR 帧，全屏原分辨率
```

- 独占全屏 → 直接抓整块显示器，无需窗口查找
- 预留 `monitor` 参数支持多显示器
- 捕获失败返回 None，由主循环跳过该帧

### 3.2 vision/preprocess.py

```python
def downsample(frame, target_width) -> (small_frame, scale)   # 等比降采样
def to_gray(frame) -> frame
def crop_roi(frame, roi) -> frame                             # roi 为 None 返回原图
def frame_diff(prev_gray, cur_gray) -> float                  # 平均绝对差 0-255
```

### 3.3 vision/matcher.py

```python
class TemplateMatcher:
    def __init__(cfg): ...        # 读取 config.templates，加载可用模板
    def match(self, frame) -> dict   # 返回 {name: MatchResult}
    def reload(self): ...            # 热加载模板（工具补截后重载）
```

- 模板缺失不报错，仅跳过该能力并在启动时警告（容错）
- 匹配分数低于 0.9 时降采样回原尺度复核一次，抑制缩放误判
- `MatchResult: { score, rect: (x, y, w, h) }`

### 3.4 vision/color_detect.py

```python
class ColorDetector:
    def match(self, frame) -> dict   # {success_ratio, fail_ratio}
```

- BGR 转 HSV → `cv2.inRange` → 像素占比统计
- ROI 优先缩小范围（HSV 计算开销较大）

### 3.5 vision/ocr.py

```python
class OcrReader:
    def __init__(cfg): ...        # RapidOCR 懒加载（首次用时才加载）
    def read(self, frame) -> str  # 识别文字
    def classify(self, text) -> Outcome | None   # 关键词命中映射
```

- 仅在疑似结果帧调用，避免逐帧 OCR 性能损耗
- 关键词表：`{"成功": SUCCESS, "失败": FAIL}`，可配置

### 3.6 core/events.py

```python
class EventType: IDLE, BALL_THROWN, RESULT_DETECTED, RESULT_TIMEOUT, COOLDOWN_END
class Outcome: SUCCESS, FAIL, UNKNOWN
@dataclass
class Event:
    type: EventType
    ts: float
    confidence: float
    detail: dict
```

### 3.7 core/state_machine.py

```python
class StateMachine:
    states: IDLE / THROWING / RESULT
    def feed(self, ev: Event) -> list[StatEvent]   # 输出用于计数的完成事件
```

#### 状态迁移表

| 当前状态 | 输入 | 迁移动作 |
|---------|------|---------|
| IDLE | BALL_THROWN（模板命中，置信度≥阈值） | → THROWING，丢球计数+1 |
| THROWING | RESULT_DETECTED（结果模板/HSV/OCR 任一确认） | → RESULT，记录 outcome |
| THROWING | 超过 `throw_timeout_s` | → RESULT，outcome=UNKNOWN |
| RESULT | `cooldown_s` 后 | → IDLE |

- 同一状态内重复命中自动忽略（天然去重）
- RESULT 阶段对 success/fail 双模板同时命中按置信度高者取

### 3.8 stats/recorder.py

```python
class Recorder:
    def record(self, ev: StatEvent): ...   # 内存计数
    def summary(self) -> dict              # 丢球/成功/失败/未知/成功率
    def flush_csv(self, row)               # 追加写行
    def save_session_json(self)            # 会话结束时落盘
```

### 3.9 main.py 主循环

```
初始化 → 预热(抓 3 帧计算基线) → 循环:
  frame = grab()（按 fps 节流）
  帧差判断（若启用）→ 变化不足可跳过重识别
  状态机输入: matcher.match → color.match → 疑似时 ocr.classify
  事件驱动状态迁移，产出统计事件
  每秒刷新控制台统计
  Ctrl+C 优雅退出 → 落盘 CSV/JSON
```

### 3.10 tools/capture_template.py（交互式截图工具）

- 实时显示当前帧
- **空格**：保存整帧到 `output/templates_raw/`
- **鼠标框选 + 回车**：裁剪存为命名模板到 `templates/`
- **R**：重置选框 | **Q**：退出
- 用途：在游戏里演示「丢球→捕捉成功→捕捉失败」，分别截图存模板

### 3.11 tools/debug_viewer.py

- 回放 `output/debug/` 下标注帧：画出匹配框 + 置信度 + 状态标签
- 支持读 config 调阈值后重算，辅助 M5 调参
